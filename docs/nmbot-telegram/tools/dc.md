# 查询 Telegram 数据中心 {#telegram-数据中心查询}

你可以用 `/dc` 查看自己、指定对话或消息中媒体的数据中心结果。群组和频道的结果可能只是推测，不能作为账号归属地或实际网络位置的证明。

<span id="_1"></span>

## 查询 Telegram 数据中心 {#查询数据中心}

在与 nmBot 的私信中发送 `/dc`，可以查询自己的结果。查询个人或对话时，nmBot 需要能读取相应头像；没有可读取的头像时，会提示无法查询。

你也可以按需要选择目标：

- 回复一条消息发送 `/dc`，查询发送者和消息中支持的媒体。
- 发送 `/dc @频道或群组用户名`，查询 nmBot 能访问的公开对话。
- 发送 `/dc 对话ID`，查询 nmBot 能访问的指定账号或对话。

在群组中发送指令时，结果还可能包含当前群组。群组启用[“限制群成员使用指令”](../group/moderation/command-restrictions.md)后，你可能无法在群组运行查询。

<span id="telegram_1"></span>

## 理解 Telegram 数据中心的结果 {#关于-telegram-数据中心}

nmBot 会返回 DC 编号和对应的地点说明，并对部分结果注明推测。这个查询不会移动账号、改变 Telegram 的连接位置，也不能判断你当前使用的网络出口。

如果结果提示找不到对话或没有头像，你可以检查目标是否可被 nmBot 访问。直接在指令后填写文件标识的查询方式目前不可用；查询媒体时，可以回复包含媒体的消息。
