# 使用“链接预览生成器”

你可以为一条文本添加指定 URL 的链接预览，保留原有文字和格式。预览能否显示，取决于 Telegram 是否支持对应链接。

## 生成“链接预览”

1. 向 nmBot 发送要展示的文本。
1. 回复这条文本，发送 `/lp https://example.com/`，把示例地址换成目标链接。你也可以使用 `/link_preview_generate`。
1. 在机器人返回的消息下调整预览选项。
1. 点按“完成”。选项按钮会移除。

你可以选择以下预览方式：

- “偏好大图像”：请求以大图像显示预览。
- “偏好小图像”：请求以小图像显示预览。
- “在文本上方显示”：把预览放到文本之前。

大图像和小图像不能同时选择，实际结果仍取决于链接提供的内容。没有回复文本或没有在指令后填写 URL 时，nmBot 会提示对应的用法。

链接可以指向 Telegram 对话、消息或外部页面等目标，部分链接不支持预览。
