# 使用实用工具 {#实用工具}

你可以用 nmBot 查询[消息元数据](message-information.md)和 [Telegram 数据中心](dc.md)，也可以把图片[转为贴纸或表情](stickers-and-emoji.md)。这些工具可以在各自支持的聊天环境中使用。

需要排版消息时，你可以生成[“链接预览”](link-preview.md)，或用[行内文字工具](inline-tools.md)转换输入内容。已有表情的 ID 和写法可以通过[自定义表情信息](custom-emoji.md)获取。

你也可以[创建和管理“指令映射”](command-mapping.md)，为自己的常用指令设置别名。

如果你遇到骚扰拦截误封，可以[查询记录并发起争议](spam-appeals.md)。所有指令的名称和参数都可以在[“指令列表”](../commands.md)中查询。
