# 查询消息元数据和消息 JSON

你可以用 `/id` 查询对话和消息的基本信息，也可以用 `/json` 查看 nmBot 收到的消息 JSON。查询结果可能包含发送者信息和消息正文，在群组中执行时，其他成员也能看到结果。

## 查询消息元数据

发送 `/id` 可以查看当前对话和本条消息的信息。要查询其他消息，可以回复那条消息发送 `/id`，结果会增加“回复消息的基本信息”。

返回内容会按消息实际具备的信息显示。你可以找到对话 ID、发送者 ID、消息类型，以及适用时的消息 ID、文件信息和话题信息。

发送者使用频道或匿名身份时，结果会显示对应的发送身份。转发消息隐藏来源时，机器人不能凭此恢复被隐藏的用户 ID。“账号注册日期”是估算值，不能用来确认真实注册时间。

## 查看消息 JSON

回复目标消息发送 `/json`。nmBot 会返回这条指令收到的消息 JSON，其中包含可见的被回复消息信息；内容过长时，会分多条发送。

你也可以单独发送 `/json` 查看本条消息。这个结果描述的是 nmBot 实际收到的信息，不会提供 Telegram 没有传给机器人的隐藏内容。

群组启用[“限制群成员使用指令”](../group/moderation/command-restrictions.md)后，你可能无法在该群组运行这些工具。完整 JSON 可能包含个人信息、文件标识和消息正文，公开转发后其他人也能读取这些内容。
