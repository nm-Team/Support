# 使用行内文字工具 {#使用行内文字工具并查询指令}

你可以在 Telegram 输入框中调用 nmBot 的文字工具，转换后直接发送结果。

<span id="_2"></span>

## 在输入框中转换文字 {#使用行内文字工具}

1. 在支持行内机器人的对话输入框中，输入 nmBot 的用户名，后接一个空格和要处理的文字，例如 `@nmnmfunbot 你好世界`。
1. 等待行内结果列表出现。
1. 点按需要的结果，将转换后的文字发送到当前对话。

你会按输入内容看到适用的结果：

- “打 字 带 空 格”：在字符间加入空格。
- “转为火星文”：转换中文文字形式。
- “转为繁体”或“转为简体”：转换中文文字。
- “整理中文和拉丁文格式”：调整适用的文字间距。

结果是否出现取决于输入文字是否适合转换。选择结果会把文字发送到当前对话，尚未选择时不会自动发送。
