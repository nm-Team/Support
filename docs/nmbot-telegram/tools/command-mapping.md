# 创建和管理“指令映射”

你可以通过“指令映射”为常用指令创建更容易输入的别名。映射按发送者身份保存，你用个人账号设置的别名会跟随这个账号，不会为群组其他成员创建同样的别名。

## 创建“指令映射”

发送 `/mapping mycredit points` 后，你以同一个身份发送 `/points` 就相当于发送 `/mycredit`。你也可以按下面的格式选择其他指令和别名：

```text
/mapping 原指令 别名
```

原指令和别名都不带 `/`。别名只能使用英文字母、数字和下划线，不能与 nmBot 已有的指令重名。同一个原指令或别名已经有映射时，需要先移除原来的映射。

创建成功后，nmBot 会提示映射的原指令和别名。你可以用自己的别名执行指令，原指令的适用对话和权限要求仍然有效。

## 移除“指令映射”

发送 `/unmapping points` 可以移除上例中的映射。你也可以用原指令名移除它：

```text
/unmapping mycredit
```

nmBot 提示移除成功后，这个别名不再生效，原指令仍然可以使用。

如果你想调整群组输入框中显示的指令，可以设置群组的[“自定义指令列表”](../group/configuration/commands.md)。
