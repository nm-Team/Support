# 使用“消息过塑”生成贴纸

你可以用“消息过塑”把文字消息制作成贴纸。nmBot 会先让你选择样式，再把生成的贴纸发到当前聊天。

## 在群组中开启“消息过塑”

群组管理员需要先[启用“群组管理功能”](../group/setup.md)，再在“群组娱乐功能”中打开“消息过塑”。修改设置需要娱乐功能的[群组功能管理权限](../group/admin-rights-and-features.md)。nmBot 需要能够发送贴纸。

你也可以在与 nmBot 的私聊中使用这个指令。

## 生成贴纸

1. 回复你希望制作成贴纸的文字消息。
1. 发送 `/quote`，也可以发送 `/q`。nmBot 会显示可用样式。
1. 点按一种样式。生成成功后，nmBot 会发送贴纸，并移除样式选择消息。

可用样式包括“寻呼机”“MineCraft 公告板”和“QuotLy 样式”。你可以点按“取消”结束这次请求。

选择“QuotLy 样式”时，消息文字、格式和发送者资料（包括可用的头像）会交给生成服务处理。生成的贴纸可能包含原消息内容和发送者名字。

## 提示“暂无支持此消息的模板。”

你选择的消息类型没有可用样式。目前可用样式处理文字消息，图片、语音或贴纸本身不能直接按文字样式生成。

## 提示请求已结束或生成出现问题

你可以重新回复原消息发送 `/quote`。旧请求被取消、完成或失效后，原来的样式按钮无法继续生成。服务暂时不可用时，可以稍后再试。
