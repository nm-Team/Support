# 将图片转为贴纸或表情 {#将图片转为贴纸或转为表情}

你可以让 nmBot 把静态图片调整为贴纸或表情所需的尺寸。机器人会返回静态贴纸，不会自动为你建立贴纸包或自定义表情包。

<span id="_2"></span>

## 选择转为贴纸或转为表情 {#选择转为贴纸或转为表情}

你需要提供照片或图片文件。转换为表情尺寸时，也可以使用静态贴纸；动态贴纸和视频贴纸不支持这项转换。

1. 向 nmBot 发送图片。
1. 回复图片发送 `/tosticker` 或 `/ts`，转换为贴纸尺寸。需要表情尺寸时，发送 `/toemoji` 或 `/te`。
1. 等待 nmBot 返回转换后的贴纸。

返回的“发送到...”按钮可以打开对话选择，让你选择这张贴纸的发送位置。

如果 nmBot 提示图片过大，你可以换用较小的图片。图片获取或转换失败时，可以重新发送支持的静态图片重试。

如果你需要已有自定义表情的 ID 和格式代码，可以[查询自定义表情信息](custom-emoji.md)。
