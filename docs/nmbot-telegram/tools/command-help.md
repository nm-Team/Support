# 查询指令用法

如果你想了解某条 nmBot 指令的用途和参数，可以使用“了解此指令”查询。你也可以查询指令的别名，或自己建立的[“指令映射”](command-mapping.md)。

## 使用“了解此指令”

发送 `/whatis ban` 可以查看 `/ban` 的说明。将 `ban` 替换为要查询的指令名，指令名不带开头的 `/`。

结果会显示已登记的指令名称、描述、参数和适用对话，并在适用时显示所需权限。出现在查询结果中，不代表你能在任意对话执行这条指令，执行时仍需满足相应要求。

## 如果提示“没有找到该指令。”

你可以在 nmBot 面板的[“指令列表”](../commands.md)中查找实际名称，再重新查询。
