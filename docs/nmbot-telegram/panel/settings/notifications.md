# 设置“接收群组呼叫管理员通知”

你可以决定自己是否接收群组成员呼叫管理员时的通知。这项个人设置会影响 nmBot 选择哪些管理员接收呼叫，群组的[“呼叫群组管理员”](../../group/moderation/call-administrators.md)设置决定呼叫的触发方式和通知位置。

## 更改“接收群组呼叫管理员通知”

关闭接收需要你的个人账号订阅 [nmBot+](../../plus/index.md)。普通账号会接收适用的呼叫通知。

1. 登录 nmBot 面板，在“设置”中打开“通知”。
1. 调整“接收群组呼叫管理员通知”开关。更改会直接保存。

关闭后，nmBot 不再把你列入这项呼叫功能的通知对象。这不会关闭群组其他管理员的通知，也不会改变 Telegram 自身的群组通知设置。

如果保存失败，nmBot 面板会提示设置更新失败，并恢复原来的开关状态。个人订阅不再生效时，会恢复接收通知。
