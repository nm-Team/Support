# 调整“面板设置”

你可以在面板的“设置”中调整个人通知和面板显示方式。[“语言”](language.md)控制面板语言，机器人私聊语言则通过 `/lang` 设置。

在[“界面与体验”](experience.md)中，你可以更改外观、交互和迷你 App 行为。[“通知”](notifications.md)决定自己是否接收群组呼叫管理员的通知。

遇到面板连接问题时，你可以查看[“服务器”和“网络测试”](connection.md)。需要测试界面选项时，可以打开[“实验性设置”](experimental.md)。
