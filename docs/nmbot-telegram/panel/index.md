# 使用“nmBot 面板” {#nmbot-面板}

<span id="nmbot"></span>

你可以在 nmBot 面板中管理群组、频道和个人配置。先[打开并登录面板](launch.md)，再选择需要管理的对话。登录授权和账号绑定可以在[管理面板登录和账号绑定](authorization.md)中了解。

你可以[添加和整理“对话”](managed-chats.md)，把常用群组或频道置顶，或从自己的列表中移除不需要显示的项目。

在[“面板设置”](settings/index.md)中，你可以调整自己的语言、通知和显示方式。外部工具可以从[“MCP 配置”](../mcp.md)接入账号有权限的操作。
