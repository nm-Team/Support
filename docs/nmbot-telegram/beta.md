# 试用 nmBot 预览版 {#关于-nmbot-预览版}

您可以用 nmBot 预览版提前体验测试中的功能。预览服务面向测试和反馈，功能可能调整或移除，也可能出现服务中断。

<span id="_1"></span>

## 选择 nmBot 预览版 {#预览版与稳定版的区别}

在 nmBot 面板的[“服务器”设置](panel/settings/connection.md)中，您可以选择列表提供的预览服务。切换后，页面会重新加载，可用功能以该服务的实际界面为准。

预览服务的数据可能与稳定服务不互通。您在预览服务中的配置和活动数据，不保证能够转移到稳定服务。

<span id="_2"></span>

## 了解 nmBot 预览版的使用范围 {#注意事项}

预览服务用于测试，不建议用于正式运营的群组或重要业务。测试服务可能出现数据丢失或泄露，其支持范围也可能有限。

您可以[联系 nmTeam 支持](support.md)反馈测试问题。未发布功能的名称、入口和行为都可能继续变化。
