# 骚扰拦截功能常见问题

如果消息被删除或账号在群组中被封禁，请先核实操作来源，再按对应原因处理。以下说明如何查询 nmBot 的拦截记录和申请复查。

<span id="为什么我发出的消息被删除我被群组封禁"></span>

## 如果你的消息被删除或被群组封禁

消息删除或群组封禁可能由多种功能触发，包括[“关键词回复”](../group/automation/keyword-replies.md)、[“发言频率限制”](../group/moderation/speaking-frequency.md)和[“骚扰消息拦截”](../group/moderation/anti-spam.md)。群组管理员、其他机器人和 Telegram 也可能执行限制。

请查看操作提示，或向群组管理员确认原因。仅凭消息消失或无法入群，无法确定是否触发了骚扰识别。

![关于不同的封禁情况](/assets/images/shared/spam%20faq.png)

<span id="如何了解我是不是被识别为了骚扰用户而被封禁的"></span>

## 如果不确定封禁是否来自骚扰拦截

你可以检查 nmBot 的拦截通知，其中的“操作 ID”可用于查询和申请复查。nmBot 无法向你发送私信时，你可能收不到通知。

你也可以在 nmBot 面板的“发现”中打开[“骚扰拦截记录查询”](../tools/spam-appeals.md)，查看当前账号近 7 日的拦截操作 ID 和时间。

<span id="_4"></span>

## 为什么 nmBot 会在群组中封禁用户？ {#你们凭什么封禁我我有说话的权利}

群组管理员决定是否启用“骚扰消息拦截”，并选择删除消息或封禁发送者等处理方式。nmBot 需要相应的 Telegram 管理员权限才能执行操作。

如果你对群组的管理规则有疑问，可以联系群组管理员了解设置。管理员可以按群组需要调整识别和处理方式。

<span id="_5"></span>

## 如果你认为自己被误封 {#我被误封了怎么办}

识别可能出现误判。你可以先查询操作记录，并检查当时的名称、简介和消息内容，例如是否包含推广文字、引流信息或大量重复内容。

如果你认为处理有误，请保留操作 ID，并按下方步骤[提交争议](#%E6%88%91%E7%9C%9F%E7%9A%84%E8%A2%AB%E8%AF%AF%E5%B0%81%E4%BA%86%E6%88%91%E6%80%8E%E4%B9%88%E8%A7%A3%E5%B0%81)。说明当时的情况有助于支持人员复查。

<span id="_6"></span>

### 名称或简介为什么会影响识别？ {#我就是想用这个名字为什么要封禁我}

名称和简介可能参与骚扰识别，其中的广告或引流文字可能影响结果。如果这些内容与账号用途不符，你可以修改后再尝试。更改资料不会自动解除已经执行的群组封禁。

<span id="_7"></span>

## 如何提交误封争议？ {#我真的被误封了我怎么解封}

在拦截通知中点按“发起争议”，核实用户 ID 和操作 ID，填写原因并提交。完整步骤和申请条件见[查询骚扰拦截记录并发起争议](../tools/spam-appeals.md)。

如果没有申请入口或操作已超过 7 天，你可以提供操作 ID，[联系 nmTeam 支持](../support.md)获取帮助。提交申请后需要等待处理，群组封禁不会立即解除。

<span id="我被-nmbot-解除封禁但群组仍然封禁着我怎么办"></span>

## 如果 nmBot 已解除封禁，但群组仍然封禁着你

群组内的封禁需要单独解除。支持人员能否处理，还取决于管理员是否允许[“nmTeam 支持解封误封用户”](../group/moderation/anti-spam.md#%E5%A4%84%E7%90%86%E8%AF%AF%E5%B0%81)。

如果支持人员无法解除该群组的封禁，或封禁来自其他管理操作，你需要联系群组管理员处理。

<span id="_8"></span>

### 如果被封禁后无法联系群组管理员 {#我都被封禁了怎么联系群组管理员}

nmTeam 支持目前不提供代为联系群组管理员的服务。如果你已经知道管理员的联系方式，或群组有公开的申诉入口，可以通过这些方式申请解除封禁。

<span id="群组管理员使用-spam-指令封禁并举报了我我会因此被封号吗"></span>

### 如果管理员使用 `/spam` 指令封禁并举报了你

`/spam` 会向 nmBot 举报骚扰，并在当前群组执行成员操作。相关识别结果可能影响账号在其他启用 nmBot 骚扰拦截功能的群组中的发言或入群。

这项指令不会直接封禁你的 Telegram 账号。如果账号受到 Telegram 平台的限制，请向 Telegram 请求帮助。
