# 如果你无法访问 nmBot 面板 {#如果您无法访问-nmbot-面板}

如果 nmBot 面板无法打开或一直停留在加载页面，可以按以下方式检查。

如果页面已经打开，但无法完成登录，请参阅[登录问题的排查方法](cannot-log-in-to-panel.md)。

- **检查网络连接：** 确认设备可以访问其他网站或服务。

- **重新加载页面：** 尝试重新加载 nmBot 面板；如果仍然异常，可以清除该网站的缓存后再次打开。

- **尝试其他浏览器：** 浏览器设置或扩展可能阻止页面加载。你可以使用其他浏览器，检查是否仍有同样的问题。

- **检查防火墙设置：** 如果设备使用了防火墙，检查它是否阻止访问 nmBot 面板。

- **查看服务状态：** 在 [nmTeam 系统状态](https://status.nmteam.xyz)中检查是否有服务异常。

如果问题仍未解决，你可以[联系 nmTeam 支持](../support.md)获取帮助。请提供错误提示、操作系统、浏览器版本，以及已经尝试的排查方法。
