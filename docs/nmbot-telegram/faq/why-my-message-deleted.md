# 如果 nmBot 删除了你发送到群组的消息

消息可能因自动管理规则或管理员操作而被删除。你可以按以下情况检查原因，并向群组管理员确认相应设置。

## 对于普通用户 { #regular-users }

对普通用户而言，多种原因都可能导致你的消息被删除：

- **[按类型自动删除消息](../group/moderation/auto-delete-messages.md)**：你的消息符合管理员设置的自动删除类型。
- **[关键词回复](../group/automation/keyword-replies.md)**：消息触发了设置为删除原消息的规则。
- **[发言频率限制](../group/moderation/speaking-frequency.md)**：你的发言触发了频率限制；频道身份暂时受限期间的后续消息可能被删除。
- **[骚扰消息拦截](../group/moderation/anti-spam.md)**：消息被识别为骚扰，包括命中群组管理员设置的自定义规则。nmBot 能向你发送私信时，你可能收到拦截通知。
- **群组管理员的操作**：管理员使用 nmBot 的指令手动删除了消息。

### 解决措施

在部分情况下，nmBot 会通过操作提示说明删除原因。

如果无法确定原因，请向群组管理员咨询，让管理员检查上述功能的设置。

如果消息被识别为骚扰，请查阅[骚扰拦截功能常见问题](spam.md)，了解查询记录和申请复查的方法。

管理员可以按群组规则，使用 `/white` 将你或你的频道加入[“群组成员白名单”](../group/moderation/whitelist.md)，豁免部分自动限制。

## 对于群组管理员

大多数群组中的限制功能对群组管理员是豁免的。但在以下情况下，群组管理员的消息也可能被删除：

- **[关键词回复](../group/automation/keyword-replies.md)**：群组管理员发送的消息触发了群组的关键词回复，且该关键词回复未设置“忽略群组管理员”并设置了删除触发的消息。
    在这种情况下，群组管理员的消息也会被删除。
- **使用了匿名频道身份发送消息**：群组管理员使用了频道身份匿名发送消息。
    在这种情况下，即使启用了“[频道透视眼](../channel/channel-perspective-eye.md)”功能，该消息也不会受到管理员豁免。
    消息删除的具体原因与[普通用户](#regular-users)相同。
    如果希望以频道身份发送消息，你可以使用 `/white` 将频道身份添加到白名单中。

### 解决措施

请检查上述情况，以确定你的消息被删除的原因。
