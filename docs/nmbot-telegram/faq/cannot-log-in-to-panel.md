# 如果你无法在 nmBot 面板登录 {#如果您无法在-nmbot-面板登录}

根据登录时出现的页面或提示，选择对应的排查方法。

<span id="卡在加载图标"></span>

## 如果页面一直显示加载图标

如果页面一直显示加载图标，未出现“通过 Telegram 登录”，请检查网络连接，并确认浏览器可以访问 Telegram 网站。

<span id="在-telegram-迷你-app-内打开时出现了登录页面"></span>

## 如果在 Telegram 迷你 App 内打开时出现登录页面

通过 Telegram 迷你 App 打开 nmBot 面板时，如果没有收到有效的登录信息，页面可能会要求重新登录。

请关闭迷你 App 后重新打开。你也可以按[打开 nmBot 面板](../panel/launch.md)中的方法，改用浏览器登录。

如果要[绑定 nmTeam 账号](../panel/authorization.md#%E7%BB%91%E5%AE%9A-nmteam-%E8%B4%A6%E5%8F%B7)，你需要先通过 Telegram 登录 nmBot 面板。

<span id="出现提示由于服务器错误登录失败"></span>

## 如果出现提示“由于服务器错误，登录失败”

请检查网络连接，稍后再试。你可以在 [nmTeam 系统状态](https://status.nmteam.xyz)中查看是否有服务异常。

<span id="允许第三方-cookie"></span>

## 如果浏览器阻止第三方 Cookie

如果浏览器阻止了 Telegram 登录窗口所需的 Cookie，你可能无法完成登录。请检查该网站的 Cookie 权限，再尝试登录。

## 其他可用措施

- **清除网站缓存：** 清除 nmBot 面板网站的缓存，重新打开页面并登录。
- **检查浏览器版本和扩展：** 更新浏览器，或暂时停用可能阻止登录窗口的扩展后重试。
- **使用其他浏览器或设备：** 检查是否只有当前浏览器或设备无法登录。
- **获取支持：** 如果仍然无法登录，你可以[联系 nmTeam 支持](../support.md)获取帮助。请说明使用的登录方式、错误提示、浏览器和设备信息。
