# 开始使用 nmBot {#nmbot-telegram-帮助文档}

您可以用 nmBot 管理 Telegram 群组和频道，设置自动回复，或使用聊天工具。首次配置时，可以[打开并登录 nmBot 面板](panel/launch.md)，再选择要管理的对话。

## 配置“群组管理功能” {#配置群组管理}

将 nmBot 添加到群组后，您可以[启用“群组管理功能”](group/setup.md)。常用的[“骚扰消息拦截”](group/moderation/anti-spam.md)、[“入群验证”](group/moderation/join-verification.md)和[“成员管理”](group/moderation/member-actions.md)都有对应的设置说明。

您也可以为群组设置[“成员消息”](group/automation/member-messages.md)、[“关键词回复”](group/automation/keyword-replies.md)和[“定时任务”](group/automation/scheduled-tasks.md)。

## 管理频道和商业机器人 {#管理频道和商业机器人}

您可以为[频道帖子](channel/posts.md)排版和添加按钮，也可以把 nmBot [连接为商业机器人](business/set-business-chatbot.md)，处理获准对话中的消息。

## 查找工具和指令 {#查找工具和指令}

[实用工具](tools/index.md)包含消息信息、贴纸、表情和链接预览等操作。[“指令列表”](commands.md)说明了如何在聊天中获取指令帮助。

需要用自然语言配置功能时，您可以打开[“nmBot Copilot”](nmbot-intelligence/copilot.md)。[“nmBot+”](plus/index.md)页面介绍了订阅范围和高级功能。

## 获取 nmBot 动态和支持 {#动态和支持}

您可以在[官方频道](https://t.me/nmbotchannel)了解发布动态和已知问题，在[更新日志](update-log/index.md)查看历史变化。遇到问题时，可以[联系 nmTeam 支持](support.md)。
