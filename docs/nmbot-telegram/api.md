# 了解 nmBot 面板 API 的接入范围 {#了解面板-api的接入范围}

如果你要把 nmBot 的配置功能接入自己的工具，可以通过 nmBot 面板 API 读取个人设置和管理有权限的对话。API 操作仍然需要有效的身份授权，也受目标功能的管理权限和订阅要求限制。

<span id="api_1"></span>

## 选择 nmBot 面板 API 的接入方式 {#选择面板-api的接入方式}

外部智能工具可以接入 [nmBot MCP](mcp.md)，由客户端发现可用操作并填写参数。你可以直接在 nmBot 面板创建访问令牌，无需把 nmBot 面板登录凭据交给外部工具。

如果你需要独立发送 HTTP 请求，可以[联系 nmTeam 支持](support.md)确认可用接口和适合你的授权方式。nmBot 面板的 MCP 令牌用于 MCP 连接，不能直接当作普通 nmBot 面板 API 的登录凭据。

<span id="api_2"></span>

## 了解 nmBot 面板 API 的操作 {#了解面板-api的操作}

公开接口提供个人设置、对话配置、关键词回复和消息模板等操作。例如：

- `getUserConfiguration`：读取当前账号的个人设置。
- `checkGroup`：读取指定群组的信息和可访问的配置，需要提供目标 `groupId`。
- `getMessageTemplates`：读取目标对话的消息模板，需要提供目标 `chatId`。

你需要按所接入工具列出的参数填写目标 ID。读取配置和执行修改的后果不同，发送消息、删除模板或更改群组设置都会作用于实际对话。

如果授权过期或权限不足，你需要重新登录或由对话管理者调整对应权限。接口名称本身不会赋予额外的管理能力。
