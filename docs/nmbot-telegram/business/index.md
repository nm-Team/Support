# 使用“商业功能”管理个人账号 {#nmbot-商业功能}

你可以把 nmBot 连接到自己的 Telegram 账号，让它以你的身份回复私信，或按时间更改个人资料。nmBot 面板的“商业”页面用于管理这些功能。

<span id="nmbot"></span>
<span id="_1"></span>

## 连接账号 {#开始使用}

先[将 nmBot 设置为商业机器人](set-business-chatbot.md)，再选择需要的功能。

<span id="_2"></span>

## 检查“商业机器人状态” {#商业机器人状态}

你可以[在 nmBot 面板查看“商业机器人状态”](set-business-chatbot.md#%E6%9F%A5%E7%9C%8B%E5%95%86%E4%B8%9A%E6%9C%BA%E5%99%A8%E4%BA%BA%E7%8A%B6%E6%80%81)，确认连接和已授权的权限。“未设置”时，nmBot 无法代你执行商业功能。

<span id="_3"></span>

## 配置“商业关键词回复” {#商业关键词回复}

你可以用[“商业关键词回复”](keyword-replies.md)匹配对方或你自己发送的消息，再以你的身份发送预设内容。

## 创建“商业定时任务” {#商业定时任务}

你可以用[“商业定时任务”](scheduled-task.md)按每天或指定星期更新名、姓、用户名和简介。例如，你可以在工作时段更改名称，在另一个时间用另一项任务更改回来。
