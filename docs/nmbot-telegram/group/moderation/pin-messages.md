# 使用 `/pin` 和 `/unpin` 管理置顶消息 {#使用-pin-指令置顶或取消置顶消息}

你可以用 `/pin` 置顶群组消息，用 `/unpin` 取消置顶。两条指令都需要回复要处理的消息。

## 前提条件 {#前提条件}

请先[启用“群组管理功能”](../setup.md)。你和 nmBot 都需要拥有置顶消息权限。

<span id="_1"></span>

## 置顶或取消置顶 {#参数}

1. 回复要处理的消息。
1. 发送 `/pin` 来置顶，或发送 `/unpin` 来取消该消息的置顶。
1. 查看指令消息上的 👌 表态。如果 nmBot 无法添加表态，它会改为发送“操作成功完成。”。

你没有回复消息时，nmBot 会要求回复目标消息；`/unpin` 不会自动选择最新的置顶消息。如果出现权限提示，请检查你的管理员权限和 nmBot 的置顶消息权限。
