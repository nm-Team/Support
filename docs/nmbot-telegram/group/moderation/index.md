# 管理消息和成员

先[启用“群组管理功能”](../setup.md)，再按群组需要选择管理方式。你可以让新成员先通过[“入群验证”](join-verification.md)，用[“骚扰消息拦截”](anti-spam.md)识别不当内容，或直接[“按类型自动删除消息”](auto-delete-messages.md)。

如果你要手动处理成员，也可以[警告成员](../warn.md)；需要限制短时间内连续发言时，配置[“发言频率限制”](../speak-limitation.md)。
