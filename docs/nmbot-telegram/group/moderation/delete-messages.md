# 使用 `/d` 删除消息 {#删除消息}

如果你需要手动清理群组中的某条消息，可以回复它并发送 `/d`。nmBot 会尝试删除目标消息和你发送的这条指令。

## 前提条件 {#前提条件}

请先[启用“群组管理功能”](../setup.md)。你和 nmBot 都需要拥有删除消息权限。请用个人身份发送指令，这项操作不支持匿名管理员或频道身份。

## 删除一条消息 {#删除一条消息}

1. 在 Telegram 群组中回复要删除的消息。
1. 输入并发送 `/d`。操作没有单独的成功提示，你可以检查目标消息是否已经消失。

如果 nmBot 提示“请回复要删除的消息”，请确认指令回复的是目标消息。如果它提示“您没有删除消息权限”，请检查你的管理员权限。

删除的消息无法恢复。你需要自动清理某类消息时，可以设置[“按类型自动删除消息”](auto-delete-messages.md)。
