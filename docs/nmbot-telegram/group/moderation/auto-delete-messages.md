# 按类型自动删除消息 { #按消息类型删除消息 }

如果你的群组不允许发送某类内容，可以让 nmBot 在收到消息后自动删除。你可以分别控制图片、链接、贴纸等类别，也可以限制成员以频道身份发言。

## 前提条件 {#前提条件}

请先[启用“群组管理功能”](../setup.md)，并为 nmBot 授予删除消息权限。配置这些规则需要修改群组发言限制的权限；涉及封禁频道或警告成员时，还需要让 nmBot 拥有封禁用户权限。

<span id="_3"></span>

## 选择要删除的消息 { #启用或禁用自动删除消息 }

1. 在面板的“对话”中选择目标群组，打开“群组管理功能”中的“自动删除”。页面会列出消息类别。
1. 在“自动删除以下类型的消息”中开启需要限制的类别。后续收到符合类别的消息时，nmBot 会尝试删除。

你也可以在群组中发送 `/config`，进入“发言限制”中的“按消息类型删除消息”。

<span id="_2"></span>

### 支持的消息类别 { #支持自动删除的消息类型 }

你可以分别开启以下项目：

- “入群系统消息”和“其他服务消息”：清理入群、退群、群组更名等系统通知。
- “长文本消息”：清理篇幅或行数过多的消息。
- “含链接消息”和“含自定义表情消息”：按消息文本或媒体描述中的相关内容清理。
- “图片”“GIF”“视频”和“视频消息”：分别限制图片、动画、普通视频和圆形视频消息。
- “贴纸”和“Premium 专享贴纸”：分别限制所有贴纸，或只限制带有 Premium 全屏动画的贴纸。
- “语音消息”：限制语音及音频消息。
- “通过机器人发送的消息”和“访客机器人消息”：分别限制行内机器人发送的消息和访客机器人消息。
- “故事”“外部引用消息”和“联系人卡片”：限制转发的故事、来自其他对话的引用和共享的联系人。

<span id="_4"></span>

## 删除消息时警告成员 { #按消息类型警告用户 }

<nmbot-plus-icon></nmbot-plus-icon> 如果群组订阅了 nmBot+，可以在“发送被禁止类型消息的用户”中开启“警告用户”。成功删除违规类别的消息后，nmBot 会警告发送者 1 次。

达到警告上限后的处理遵循[“警告”](warnings.md)的设置。清理系统服务消息不会因此警告成员。

<span id="_5"></span>

## 限制频道身份发言 { #限制频道身份发言 }

在“以频道身份发送的消息”中开启“自动删除”，nmBot 会删除以频道身份在群组中发送的消息。你可以将允许发言的频道加入群组白名单。

<span id="自动封禁以频道身份发送消息的用户的频道"></span>
<span id="_6"></span>

开启“删除时封禁该用户的所有频道”后，nmBot 会在删除时尝试封禁发送消息的频道。

<span id="主动封禁入群用户频道"></span>
<span id="_7"></span>

如果你还希望成员加入时就限制其个人频道，可以开启“主动封禁入群用户频道”。这需要同时启用上述频道封禁选项和[“入群验证”](join-verification.md)。

## 注意事项 {#注意事项}

消息删除后无法恢复。

按类型清理普通消息时，nmBot 会忽略群组管理员和群组白名单中的发送者。关联频道自动转发到讨论群的帖子不会作为普通频道身份消息删除。

如果消息没有按预期删除，请先检查“群组管理功能”和该类别的开关，再检查 nmBot 的删除消息权限。如果你自己是管理员，请用普通成员的消息检查效果。
