# 查看“操作记录”并设置“操作记录频道” {#操作记录}

你可以用“操作记录”查找管理员通过 nmBot 完成的操作和部分群组变动。记录会显示时间、操作人、操作类型和相关内容；你还可以将新记录发送到“操作记录频道”。

<span id="_1"></span>

## 前提条件 {#开启条件}

群组中有至少 200 名成员后，才可以开启“操作记录”功能。请先[启用“群组管理功能”](../setup.md)，并确保你拥有管理操作记录的[群组功能管理权限](../admin-rights-and-features.md)。群组管理员可以查看已有记录。

<span id="_2"></span>

## 启用“操作记录” {#开启方法}

1. 在 nmBot 面板的“对话”中选择目标群组，找到“操作记录”部分。
1. 打开“启用”。后续支持记录的操作会出现在群组的操作记录中。

你也可以在群组的 `/config` 菜单中设置“操作记录”。

<span id="_3"></span>
<span id="提示"></span>

“操作记录”不会记录群组中的所有行为。关闭功能后，后续操作不再作为可查看的群组记录保存；关闭前已有的记录仍可在 nmBot 面板查看。

<span id="_5"></span>
<span id="nmbot"></span>

## 在 nmBot 面板查看“操作记录” {#在-nmbot-面板查看操作记录}

1. 在群组页面的“操作记录”部分点按“查看操作记录”。页面会列出记录。
1. 如需查找特定操作，点按“搜索”，打开“过滤器”。你可以选择多个“操作类型”，或填写“用户 ID”筛选操作人。
1. 点按“继续加载”查看更早的记录，或点按“刷新”重新加载结果。

当页面显示“暂无操作记录”时，还没有可显示的记录。你关闭过滤器后，筛选条件会被清除，页面会重新显示群组记录。

<span id="_4"></span>

## 绑定“操作记录频道” {#绑定操作记录频道}

你和 nmBot 都必须在目标频道拥有发送帖子权限。

1. 在要绑定的频道中邀请 nmBot，并授予发送帖子权限。
1. 获取频道 ID。你可以将频道消息转发至 nmBot，再对转发消息回复 `/id`。
1. 在群组页面的“操作记录”部分点按“设置操作记录频道 (可选)”。
1. 输入频道 ID 并确认。保存成功后，该设置会显示“已设置”，后续新记录会发送到此频道。

如果 nmBot 面板提示“频道 ID 不正确”，请检查输入的频道 ID。无法保存时，请检查你和 nmBot 在目标频道的权限。

要停止向频道发送记录，重新打开“设置操作记录频道 (可选)”并点按“停用”。这不会删除已经发送的频道消息，也不会关闭群组的“操作记录”。
