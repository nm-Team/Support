# 启用“骚扰消息拦截” { #自动识别并删除骚扰消息 }

如果你的群组经常出现广告或诈骗消息，可以开启“骚扰消息拦截”。你可以为不同识别服务分别选择删除消息，或在删除消息的同时封禁发送者。

## 前提条件 {#前提条件}

请先[启用“群组管理功能”](../setup.md)，并确保 nmBot 拥有删除消息和封禁用户的权限。你需要拥有修改群组发言限制的权限；如果页面提示没有权限，请让群主检查[群组功能管理权限](../admin-rights-and-features.md)。

<span id="_2"></span>

## 选择识别服务和处理方式 { #配置 }

1. 在面板的“对话”中选择目标群组，打开“群组管理功能”中的“骚扰消息拦截”。页面会列出可用的识别服务。
1. 在你要使用的服务中选择处理方式。你可以将不同服务设置为不同操作。

每项服务支持以下处理方式：

- “关”：不使用这项服务检查消息。
- “删除”：删除被这项服务识别为骚扰的消息。
- “删除并封禁”：删除消息，并按相关设置处理发送者。

你也可以在群组中发送 `/config`，进入“发言限制”中的“骚扰消息拦截”设置。

“nmBot 反骚扰系统认定为广告的消息”可以结合发送者、消息文本、转发来源和贴纸包等信息识别骚扰内容。启用后，管理员和群组白名单中的成员会被忽略；关联频道自动转发到群组的帖子也不会按普通骚扰消息处理。

如果需要检查其他机器人发送的消息，开启“识别其他机器人发送的消息”。

<span id="启用-nmbot-智能骚扰拦截"></span>

在“nmBot 智能”分组中，设置“nmBot 智能识别为骚扰的消息”的处理方式，再调整“nmBot 智能识别敏感度”。滑动条越往右越严格，也可能增加误判。

这项功能仍为 Beta 版，目前仅检查简体中文消息，在特定语境下可能出现较多误判；选择“删除并封禁”后，被误判的消息发送者也会被封禁。

<span id="_4"></span>

#### 设置“智能操作” { #智能操作 }

当处理方式为“删除”时，你还可以开启“nmBot 智能智能操作”。开启后，nmBot 会根据消息的骚扰程度选择只删除消息或封禁发送者，因此“删除”设置下也可能发生封禁。

<span id="combot-anti-spam"></span>

### “Combot Anti-Spam” { #combot-anti-spam-集成 }

你可以为“被 Combot CAS 标记的用户”选择处理方式。该服务由 Combot 提供，用于识别已被 Combot Anti-Spam 标记的用户。

### “AdBye” { #adbye }

如果页面中显示“AdBye”分组，你可以为“AdBye 识别为广告的消息”选择处理方式。启用后，可用“AdBye 识别灵敏度”调整严格程度，越往右越严格。

!!! note "第三方服务"

    AdBye 由第三方提供。启用后，群组中需要识别的消息文本会发送到该服务。

## 调整封禁和提示行为 {#调整封禁和提示行为}

如果你希望在执行操作后向群组成员发送说明，可以开启“操作时发送提示消息”。

选择“删除并封禁”后，你可以开启“消息文本或转发来源触发仅封禁短时间多次触发用户”。这样，当消息文本或转发来源触发规则时，nmBot 会先删除消息，在短时间内重复触发后再封禁。发送者本身被识别为骚扰用户，以及“nmBot 智能智能操作”决定封禁的情况，仍可能直接封禁。

## 添加“自定义规则” { #自定义规则 }

<nmbot-plus-icon></nmbot-plus-icon> 如果群组订阅了 nmBot+，你可以打开“自定义规则”，补充适合本群组的识别规则。自定义规则配合 nmBot 反骚扰系统使用，因此请同时开启“nmBot 反骚扰系统认定为广告的消息”。

## 处理误封 {#处理误封}

如果成员被误封，群组管理员可以解除封禁。需要避免同一成员再次被识别时，可以将其加入群组白名单；骚扰拦截提示中的白名单操作需要管理员拥有封禁用户的权限。

你也可以开启“允许 nmTeam 支持解封误封用户”。开启后，如果 nmTeam 支持确认某次骚扰拦截属于误封，就可以根据该次操作记录尝试在受影响群组中解除封禁。

成员可以[查询拦截记录并发起争议](../../tools/spam-appeals.md)，或向 [nmTeam 支持](../../support.md)提供拦截提示中的“操作 ID”。这项入口根据骚扰拦截操作记录处理误封；其他原因造成的限制，请由群组管理员检查和处理。你可以随时在“骚扰消息拦截”页面关闭该授权。

## 常见问题 { #关于骚扰拦截功能的常见问题 }

如果正常消息反复被删除，请检查是哪项识别服务触发，调整对应服务的处理方式或灵敏度。更多问题可以查看[骚扰拦截常见问题](../../faq/spam.md)。
