# 设置“入群验证” { #入群验证 }

如果你希望新成员在验证身份后才能发言，可以开启“入群验证”。新成员需要按验证消息中的提示完成操作，未通过的成员会按你设置的时长被封禁。

## 前提条件 {#前提条件}

请先[启用“群组管理功能”](../setup.md)，并为 nmBot 保留封禁用户的权限。你需要拥有修改“入群验证”的[群组功能管理权限](../admin-rights-and-features.md)。如果你还希望清理入群系统消息或验证消息，也需要为 nmBot 授予删除消息权限。

## 启用“入群验证” {#启用入群验证}

1. 在 nmBot 面板的“对话”中选择目标群组，打开“群组管理功能”中的“入群验证”。页面会显示验证方式。
1. 将“入群验证”从“关闭”改为所需方式。页面会显示该方式的后续选项。
1. 设置“超时时间”和“默认封禁时长”。后续加入的成员会按这些设置进行验证。

![入群验证设置中选择订阅频道验证的控件](/assets/images/nmbot/guides/join-verification-mode.png){ width="360" }

你也可以在群组中发送 `/config`，从设置菜单调整入群验证。

<span id="_2"></span>

### 选择验证方式 { #验证方式 }

你可以根据群组需要选择：

- “算术验证”：新成员点按正确答案来完成算术题。
- “网页验证”：新成员打开验证网页，按页面提示完成验证。
- “订阅频道验证”：新成员加入指定频道后，返回验证消息确认。
- “发送贴纸验证”：新成员按提示发送贴纸完成验证。使用入群请求验证时，这种方式会改为算术验证。
- “星币验证”：新成员按验证消息中的付款入口确认支付；确认后验证即通过，这 1 颗 Telegram 星币不会被实际扣除。
- <nmbot-plus-icon></nmbot-plus-icon> “半自动入群验证”：符合自动拒绝条件的成员会被拒绝，其余成员等待管理员审批。
- “拒绝新成员加入”：拒绝新成员加入群组。

<span id="半自动入群验证"></span>

如果你选择“半自动入群验证”，待验证的成员会一直等待，直到有管理员处理。这种方式适合需要人工确认成员资格的群组。

## 设置验证位置和超时时间 {#设置验证位置和超时时间}

“验证位置”决定普通入群验证是在群组中进行，还是让成员跳转到与 nmBot 的私信。开启“通过对话加入请求验证”后，nmBot 会处理 Telegram 的加入请求，这类验证始终在私信中进行。

普通验证的默认“超时时间”为 120 秒。未订阅的群组可以选择 120 秒或 180 秒。<nmbot-plus-icon></nmbot-plus-icon> nmBot+ 群组还可以选择 60 秒、90 秒、300 秒、600 秒、900 秒、1800 秒或 3600 秒。

“默认封禁时长”决定未通过验证的成员被封禁多久。<nmbot-plus-icon></nmbot-plus-icon> 订阅群组还可以分别为骚扰用户和被管理员拒绝的用户设置封禁时长，并调整“最大尝试验证次数”。请留意这些设置可能让成员在后续申请加入时继续受到限制。

## 设置“验证频道” {#设置验证频道}

如果你选择“订阅频道验证”，请完成频道绑定。**如果你只选择验证方式，没有设置有效的频道，新成员会被直接通过。**

你和 nmBot 都需要是目标频道的管理员，nmBot 还需要拥有添加用户权限。你在群组中也需要拥有修改入群验证的权限。

1. 在“入群验证”页面打开“验证频道”。页面会显示“频道 ID 或用户名”输入框。
1. 输入频道 ID 或 `@频道用户名`。
1. 点按“保存”。如果保存成功，你会看到“设置成功”，请确认显示的是你要绑定的频道。

你也可以在群组中使用 `/sc 频道ID或@频道用户名`，例如 `/sc -1001234567890`。nmBot 会自动生成所需的邀请链接。请将示例中的频道替换为实际值。

如果保存失败，先检查你和 nmBot 的频道管理员身份，再检查 nmBot 是否拥有添加用户权限。[频道验证无法工作](../../faq/channel-verification-not-working.md)中列出了其他检查方法。

## 设置自动通过和自动拒绝 { #自动通过和自动拒绝 }

在“自动化”中，你可以开启以下选项：

- “自动通过 Premium 用户入群”：符合条件的 Telegram Premium 成员可以免于手动完成验证。
- “自动拒绝非 Premium 用户入群”：拒绝没有 Telegram Premium 的新成员。
- “自动拒绝 nmBot 判断为骚扰的用户入群”：在入群时检查并拒绝被识别的骚扰用户。

群组白名单中的成员会自动通过入群验证。<nmbot-plus-icon></nmbot-plus-icon> 订阅群组还可以为拒绝骚扰用户补充“自定义规则”。

<span id="_5"></span>

## 添加自定义验证文本 { #自定义入群验证消息 }

<nmbot-plus-icon></nmbot-plus-icon> 如果群组订阅了 nmBot+，你可以打开“验证消息文本”，输入群规提示或说明。此处最多可填写 500 个字符，文本会随验证消息显示。

<span id="_6"></span>

## 查看和处理验证记录 { #入群验证历史记录 }

在“入群验证”中打开“入群验证记录”，可以查看正在进行、已通过和已拒绝的验证。免费群组可查看最近 15 分钟的记录。<nmbot-plus-icon></nmbot-plus-icon> nmBot+ 群组可查看最近 15 天的记录。

你可以在验证消息中处理待验证成员，也可以在记录详情中执行页面提供的封禁或取消封禁操作。相关操作仍需要对应的成员管理权限。

<span id="_7"></span>

## 注意事项 { #疑难解答 }

已经由 Telegram 加入请求批准的成员，不会在进入群组后再进行一次普通入群验证。如果你希望 nmBot 在批准前完成验证，请开启“通过对话加入请求验证”。

如果群组还有其他机器人限制新成员发言，请检查它们的验证设置，避免多套验证同时影响成员权限。
