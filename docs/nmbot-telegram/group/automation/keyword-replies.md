# 创建和管理“关键词回复” { #关键词回复 }

如果你希望成员发送“群规”时收到说明，可以创建关键词回复。你也可以让符合条件的消息触发删除、警告或禁言等操作，并为不同规则设置不同的回复内容。

## 前提条件 {#前提条件}

你需要是群组管理员，并拥有管理“关键词回复”的[群组功能管理权限](../admin-rights-and-features.md)。涉及删除消息、警告或禁言时，请先[启用“群组管理功能”](../setup.md)，并为 nmBot 授予对应权限。

<span id="_2"></span>

## 创建一条群规回复 { #如何设置关键词回复 }

1. 在 nmBot 面板的“对话”中选择目标群组，打开“关键词回复”。页面会显示现有规则。
1. 点按“添加”，在“消息文本”中输入 `^群规$`。这表示只匹配内容恰好为“群规”的文本。
1. 在“回复”中选择已有[“消息模板”](message-templates.md)，或点按“添加模板”创建群规说明。
1. 保持“启用”开启，点按“保存”。看到“保存成功！”后，在群组中发送 `群规` 检查回复。

如果你在编辑器中创建或修改了消息模板，请同时保存关键词回复本身，确保模板已被这条规则选中。

## 设置匹配内容 {#设置匹配内容}

你可以在“关键词”中选择要检查的内容。这些条件支持正则表达式；普通文字也会作为匹配规则处理，例如 `群规` 可以匹配包含这两个字的消息，`^群规$` 只匹配完整内容。

<span id="贴纸-emoji"></span>

- “消息文本”：检查消息文字或媒体描述。
- “文件名”：检查成员发送的文件名称。
- “贴纸 Emoji”：检查贴纸关联的 Emoji，例如 `😭`。
- “贴纸包名称”：检查分享链接中的名称。例如 `https://t.me/addstickers/UtyaDuck` 中的名称是 `UtyaDuck`，与贴纸包界面显示的标题可能不同。

输入规则后，可以点按“测试匹配”，输入一段样本文字，检查编辑器显示的匹配结果。如果编辑器提示正则表达式不合法，请先修正规则再保存。

<span id="_8"></span>

### 匹配消息发送者 { #匹配消息发送者 }

你可以按成员昵称、用户名或用户 ID 限定发送者。例如，在“匹配消息发送者”中输入 `@example_user` 或 `id:123456789`。如果你要匹配 Telegram Premium 成员，输入 `is_premium`。

多个可选条件可以用 `|` 连接。例如 `@example_user|id:123456789` 可以匹配该用户名或该用户 ID。

<span id="_9"></span>

### 匹配转发者名称 { #匹配转发者名称 }

如果你要按转发来源筛选消息，在“匹配转发者名称”中填写规则。此处检查的是转发来源的名称；Telegram 隐藏转发来源时，可用信息会受到限制。

<span id="_10"></span>

### 决定条件如何组合 { #独立匹配 }

“独立匹配”决定内容条件和发送者等条件如何配合：

- 开启时，内容、发送者、转发者或情绪条件中，任意一项匹配就会触发。这适合“任何人发送群规关键词都回复”，或“指定成员发送任何消息都触发”的规则。
- 关闭时，需要先匹配消息内容或情绪，再同时满足你填写的发送者和转发者条件。这适合“只在某位成员发送指定内容时触发”的规则。

例如，你只希望 `@example_user` 发送 `群规` 时收到回复，就将“消息文本”设为 `^群规$`，“匹配消息发送者”设为 `@example_user`，并关闭“独立匹配”。如果你只填写发送者条件，请开启“独立匹配”。

<span id="beta"></span>

### 识别文本情绪 { #情绪识别-beta-版 }

<nmbot-plus-icon></nmbot-plus-icon> 订阅 nmBot+ 的群组可以开启“识别文本情绪”，识别仇视、侮辱、脏话、暴力等内容。你可以分别选择各类内容的识别严格程度，再设置触发后的回复和操作。

情绪识别也参与“独立匹配”的条件组合。请用符合群组实际语境的消息检查效果，再决定是否配合警告或禁言。

<span id="_11"></span>

## 选择回复内容 { #回复 }

在“回复”中选择要发送的消息模板。要复用已有模板，请展开“其他模板”；如果它被隐藏，点按该分组旁的眼睛按钮显示。

<span id="随机回复"></span>
<span id="_13"></span>

通常，一条规则会发送你选中的全部模板。开启“随机回复”后，nmBot 会从所选模板中抽取回复；<nmbot-plus-icon></nmbot-plus-icon> 订阅群组可以调整“回复消息数”。

如果只需要删除消息、警告或禁言，也可以不选择回复模板。使用这些操作时，建议同时设置一条说明，让成员知道为什么受到处理。

<span id="_12"></span>

## 调整触发条件 { #触发条件 }

你可以在“触发条件”中进一步限定规则：

- “忽略群组管理员”：群组管理员发送的消息不会触发该规则；用管理员账号测试时看不到触发效果。
- “匹配编辑后的消息”：让成员编辑消息后也能触发检查。
- “忽略拉丁文字母大小写”：让 `Hello` 和 `hello` 等文本按相同内容匹配。
- “忽略中文字符简繁体”：让 `开心` 和 `開心` 等文本按相同内容匹配。
- “冷却时间”：同一成员触发该规则后，在你选定的时间内不会重复触发。

你可以按需要启用以下操作：

- “自动删除”：分别设置何时删除触发规则的消息和 nmBot 的回复消息。删除后无法恢复。
- “添加确认按钮”：让成员点按回复中的确认按钮后删除该回复。
- “优先跨消息回复”：成员回复另一条消息并触发规则时，让 nmBot 回复被引用的那条消息。
- “对回复消息禁用 nmartChat”：避免成员回复这条自动回复时触发 nmartChat。该选项不适用于“拷贝消息”模板。
- “禁言用户”：限制触发者发言，可以选择时长或永久禁言。频道身份仅支持永久禁言。
- <nmbot-plus-icon></nmbot-plus-icon> “警告发送者”：给触发者增加警告；达到警告上限后的处理由[“警告”](../moderation/warnings.md)的设置决定。

## 查找、修改和删除规则 {#查找修改和删除规则}

在“关键词回复”列表中点按“搜索”，可以按关键词查找规则。列表会标出删除触发消息、禁言发送者和警告次数等操作，便于你检查会影响成员的规则。

打开规则后，可以修改条件或关闭“启用”，再点按“保存”。要删除规则，可使用列表中的“选择”和“删除已选中”。确认删除后无法撤销。

## 常见问题 { #遇到问题 }

<span id="提示我们无法完成操作因为关键词回复数量达到上限"></span>
<span id="_18"></span>

### 无法继续添加规则 {#无法继续添加规则}

如果你看到“关键词回复数量已达上限”，请删除不再需要的规则，或查看页面中的 nmBot+ 升级选项。仅停用规则不会删除该规则。

<span id="页面提示我们无法完成操作因为关键词回复设置不合法"></span>
<span id="_19"></span>

### 保存时提示匹配方式或正则表达式有问题 {#保存时提示匹配方式或正则表达式有问题}

至少填写一种匹配条件。检查各个输入框中的表达式，并使用“测试匹配”确认内容。如果规则只填写发送者条件，请开启[“独立匹配”](#%E7%8B%AC%E7%AB%8B%E5%8C%B9%E9%85%8D)，才能按预期触发。

### 规则保存了却没有回复 {#规则保存了却没有回复}

先检查“启用”和“独立匹配”，再检查管理员忽略、编辑消息和冷却时间等条件。如果规则已经触发，但提示消息模板发送失败，请检查[“消息模板”](message-templates.md#%E6%B6%88%E6%81%AF%E6%A8%A1%E6%9D%BF%E5%8F%91%E9%80%81%E5%A4%B1%E8%B4%A5)的格式、权限和来源。
