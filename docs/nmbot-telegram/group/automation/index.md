# 设置“自动回复与消息” {#自动回复与消息}

<span id="_1"></span>

如果你希望成员发送“群规”时收到固定说明，可以创建[“关键词回复”](keyword-replies.md)。回复内容由[“消息模板”](message-templates.md)提供，同一个模板也能用于其他支持模板的群组功能。

需要按时间执行操作时，可以[创建“定时任务”](scheduled-tasks.md)。你也可以设置[“入群欢迎”“退群消息”和“入群请求通知消息”](member-messages.md)，在成员加入、退出或申请加入时发送内容。
