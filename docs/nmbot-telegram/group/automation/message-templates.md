# 创建和复用“消息模板” { #消息模板 }

如果你希望多个功能发送同一份群规或说明，可以将内容保存为消息模板，再在各功能中选择它。同一个对话中的模板可以复用，修改模板后，引用它的功能会使用新的内容。

## 前提条件 {#前提条件}

在群组中创建或管理模板，需要拥有管理“关键词回复”的[群组功能管理权限](../admin-rights-and-features.md)。如果你要拷贝另一个对话中的消息，还需要是来源对话的管理员，并确保 nmBot 能访问原消息。

## 创建一条文本模板 {#创建一条文本模板}

1. 打开目标群组的“消息模板”，或在[“关键词回复”](keyword-replies.md)等功能的模板选择区域点按“添加模板”。编辑器会显示一条新模板。
1. 填写“名称”。它帮助你查找模板，不会作为消息内容发送。
1. 将“消息类型”设为“文本”，在“消息文本”中填写内容。
1. 点按“保存”。保存后，模板会出现在该对话的模板列表中。

如果你从某个功能进入编辑器，还需要在该功能中确认已选中模板，并保存该功能的设置。创建模板本身不会自动向群组发送消息。

## 选择消息类型 {#选择消息类型}

除文本外，你还可以创建以下模板：

- “语音消息”：填写要发送的语音文件 ID。
- “贴纸”：填写要发送的贴纸文件 ID。
- “拷贝消息”：填写原消息链接，可以添加多条消息。

要获取文件 ID，可以在 Telegram 中向相应的语音或贴纸回复 `/id`，再将 nmBot 返回的文件 ID 填入编辑器。

使用“拷贝消息”时，从 Telegram 消息菜单拷贝消息链接，再填写到“拷贝消息链接”中。从本对话拷贝时，可以只填写消息 ID。启用了内容保护的原消息无法拷贝。

## 为文本添加格式 { #如何为消息模板添加格式 }

“解析模式”决定文本如何显示。选择“无 (默认)”时，nmBot 会按普通文字发送。需要粗体、链接或代码等格式时，可以选择 Telegram 的 Markdown、MarkdownV2 或 HTML。

例如，将“解析模式”设为 HTML 后，可以在“消息文本”中输入：

```html
<b>群规</b>
请友善交流，不要发送广告。
```

Telegram 的 Markdown 和 MarkdownV2 与一般文档网站的 Markdown 不完全相同。更多写法可查看 [Telegram 的格式化说明](https://core.telegram.org/bots/api#formatting-options)。

<nmbot-plus-icon></nmbot-plus-icon> 在订阅 nmBot+ 的对话中，文本模板还可以选择“富文本 Markdown”或“富文本 HTML”。这些模式与普通文本模式的可用选项不同，请在发送前检查实际预览。

### 发送预览消息 {#发送预览消息}

填写文本并选择解析模式后，点按“发送预览消息”。nmBot 会尝试将预览发送到你与它的私信中，供你检查格式和链接预览。若提示发送成功，请打开私信查看；如果你尚未与 nmBot 私信，请先打开机器人并发送 `/start`。

## 插入用户和时间信息 { #消息模板变量 }

部分功能在发送模板时会提供触发成员的信息，你可以在文本中使用以下占位符：

<span id="_3"></span>

### 用户信息 { #用户信息变量 }

- `{username}`：成员的显示名称。
- `{userFirstName}`：成员的名。
- `{userLastName}`：成员的姓。
- `{userUserName}`：成员的用户名。

如果该成员没有姓或用户名，相应内容会留空。如果使用模板的功能没有提供成员信息，用户信息占位符会保留原样。请在实际使用模板的功能中检查效果。

<span id="_4"></span>

### 日期和时间 { #时间变量 }

你可以使用 `{date}`、`{time}` 或 `{dateTime}` 插入发送时的日期、时间或两者，也可以用 `{year}`、`{month}`、`{day}`、`{hour}`、`{minute}` 和 `{second}` 分别插入对应部分。

如果你要指定时区，可以写成 `{date:+8}` 或 `{time:-5}`，分别表示 UTC+8 的日期和 UTC-5 的时间。如果你不指定时区，日期和时间会按 UTC 计算。

## 设置按钮和发送选项 {#设置按钮和发送选项}

你可以在“按钮”区域添加消息按钮，并在“发送选项”中调整以下行为：

- “禁用通知”：让消息静音发送。
- “启用内容保护”：限制接收者转发、拷贝或保存消息。

普通文本模板还可以控制“链接预览”，选择预览的链接、图像大小，以及是否“在文本上方显示”。不同功能和消息类型支持的选项可能不同，请检查实际发送结果。

## 修改和删除模板 {#修改和删除模板}

在模板列表中使用“搜索”查找模板，再点按“编辑”修改。多个功能共用一个模板时，这些功能发送的都会是新内容。

删除模板无法撤销。其他功能如果仍引用被删除的模板，将无法发送相应消息。

## 常见问题 { #消息模板常见问题 }

<span id="_7"></span>

### 消息模板发送失败 { #消息模板发送失败 }

如果文本无法发送，先将“解析模式”改为“无 (默认)”并重新预览。若普通文字可以发送，检查原格式中的标签和转义字符。

如果拷贝消息失败，请检查原消息是否仍然存在、是否受到内容保护，以及你和 nmBot 是否有权访问来源对话。文件或贴纸无法发送时，请重新用当前机器人获取文件 ID。

如果保存时提示“富文本格式仅可在 nmBot+ 对话中使用”，请确认当前对话的订阅状态，或改用普通解析模式。看到内容无法用于模板的提示时，请调整内容后重试。
