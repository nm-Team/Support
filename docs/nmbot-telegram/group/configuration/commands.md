# 设置“自定义指令列表”和“指令映射”

你可以为群组调整输入框中的指令菜单，也可以为自己的常用指令添加别名。“自定义指令列表”作用于群组菜单，“指令映射”跟随发送者身份使用。

## <nmbot-plus-icon></nmbot-plus-icon> 设置“自定义指令列表”

目标群组需要订阅 nmBot+，你需要拥有修改其他管理功能的[群组功能管理权限](../admin-rights-and-features.md)。

1. 在面板的“对话”中选择目标群组，打开“自定义指令列表”。
1. 勾选需要在 Telegram 输入框菜单中显示的指令。至少保留一项。
1. 点按“保存”。看到“保存成功”后，群组的指令菜单会使用这次选择。

管理员和普通成员可能看到不同的菜单。隐藏菜单项不会关闭对应功能，知道指令的成员仍然可以手动输入，指令本身的权限要求也不会改变。

你可以重新打开页面，点按“取消自定义设置”恢复默认菜单。

## 创建“指令映射”

你可以把常用指令映射为更容易输入的别名。例如，发送 `/mapping mycredit points` 后，你以同一个身份发送 `/points` 就相当于发送 `/mycredit`。

```text
/mapping 原指令 别名
```

原指令和别名都不带 `/`。别名只能使用英文字母、数字和下划线，不能与 nmBot 已有的指令重名。同一个原指令或别名已经有映射时，需要先移除原来的映射。

映射按发送者身份保存。你用个人账号设置的别名会跟随这个账号，不会为群组其他成员创建同样的别名，也不会绕过原指令的权限检查。

## 移除“指令映射”

发送 `/unmapping points` 可以移除上例中的映射。你也可以用原指令名移除它：

```text
/unmapping mycredit
```

nmBot 提示移除成功后，这个别名不再生效，原指令仍然可以使用。
