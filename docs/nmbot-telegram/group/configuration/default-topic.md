# 设置默认话题

如果你的超级群组启用了话题，可以为 nmBot 指定默认话题。后续的欢迎消息、群内入群验证提示、退群消息和定时任务消息等，会使用这个话题。

## 更改默认话题

你需要是群组管理员，并以个人身份或群组匿名管理员身份操作。频道身份不支持这项指令。

1. 在群组中打开你希望接收消息的话题。
1. 在这个话题中发送 `/default_topic`，也可以发送 `/dt`。
1. 如果设置成功，你会看到“已将此话题设为默认话题。”，后续使用默认话题的消息会发到这里。

你可以在另一个话题中再次发送指令来更改选择。已经发送的消息不会移动，针对某条消息的普通回复也不会因此全部转到默认话题。

<span id="提示群组没有启用话题功能"></span>

## 如果提示群组没有启用话题功能

普通群组或没有开启话题的超级群组无需设置默认话题。如果提示没有权限，需要由群组管理员执行指令。
