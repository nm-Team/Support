# 调整群组配置 {#备份与迁移}

<span id="_1"></span>

如果你准备调整大量设置，或要为另一个群组沿用已有规则，可以先[导出配置，再按需导入](import-export.md)。导入前会列出将修改的设置和新增内容，你可以检查并忽略不需要修改的设置。

你可以调整[“自定义指令列表”](commands.md)，选择[“群组语言”](language.md)，或指定消息发送的[“默认话题”](default-topic.md)。
