# 设置群组语言

你可以为群组服务消息和发给匿名管理员的回复选择语言。通常，nmBot 回复其他成员时仍会使用成员自己的语言设置；打开“覆盖用户语言”后，这些回复也会改用群组语言。

## 更改“群组语言”

你需要拥有修改其他管理功能的[群组功能管理权限](../admin-rights-and-features.md)。

1. 在 nmBot 面板的“对话”中选择目标群组，打开“语言和地区”。
1. 在“群组语言”中选择需要的语言。更改会直接保存，后续群组服务消息使用这个语言。
1. 如果希望对成员的回复也统一语言，打开“覆盖用户语言”。之后的回复会优先使用群组语言。

关闭“覆盖用户语言”后，成员的个人语言会重新用于各自的回复。这个设置不会修改成员原来保存的个人语言，也不会更改他们看到的 nmBot 面板语言。

## 在群组中发送 `/lang`

你以个人身份发送 `/lang` 时，修改的是自己的首选语言。需要修改整个群组的语言时，请使用 nmBot 面板中的“群组语言”。
