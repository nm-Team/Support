# 启用“群组管理功能” { #授予-nmbot-管理员权限并配置功能 }

如果你希望 nmBot 删除违规消息、限制成员发言或进行入群验证，需要将它设为群组管理员，再启用“群组管理功能”。添加机器人后，这项功能默认关闭，需要你主动开启。

## 前提条件 {#前提条件}

你需要拥有为群组添加管理员的权限。修改 nmBot 设置还需要对应的[群组功能管理权限](admin-rights-and-features.md)；通常由拥有“封禁用户”权限的管理员操作，群主也可以调整授权。

<span id="telegram-nmbot"></span>

## 授予 nmBot 管理员权限 { #在-telegram-中授予-nmbot-管理员权限 }

1. 打开 Telegram 的群组管理页面，进入“管理员”。这里会列出群组的管理员。
1. 选择“添加管理员”，找到你使用的 nmBot。
1. 为 nmBot 开启“删除消息”和“封禁用户”权限后保存。如果你需要让它置顶消息，再授予“置顶消息”权限。

不同 Telegram 客户端的按钮名称可能略有不同。“封禁用户”权限是开启“群组管理功能”的必要条件，“删除消息”权限则用于实际删除违规消息。

<span id="nmbot_1"></span>

### 添加机器人时直接设为管理员 { #将-nmbot-添加为管理员 }

你也可以从 nmBot 的资料页选择“添加到群组或频道”，选中目标群组，并在添加页面授予上述管理员权限。

## 开启群组管理功能 {#开启群组管理功能}

1. [打开面板](../panel/launch.md)，在“对话”中选择目标群组。若找不到群组，先[添加群组到面板](reg-panel.md)。
1. 在“群组管理功能”分组中打开“启用”。开启后，下方会出现“群组管理功能”设置入口。
1. 点按“群组管理功能”，打开你要使用的功能并配置。仅开启“启用”不会自动开启所有管理选项。

你也可以在群组中发送 `/config`，使用消息中的设置菜单开启和调整功能。

## 选择所需的功能 {#选择所需的功能}

如果你要识别广告和骚扰内容，配置[“骚扰消息拦截”](moderation/anti-spam.md)。如果你希望新成员通过验证后才能发言，配置[“入群验证”](moderation/join-verification.md)。要直接禁止图片、链接或其他消息类别，使用[“自动删除”](moderation/auto-delete-messages.md)。

对于自动发送群规、帮助说明等内容，可以创建[关键词回复](automation/keyword-replies.md)。你也可以[导入已有配置](configuration/import-export.md)，在导入前检查哪些设置将被修改。

## 注意事项 {#注意事项}

nmBot 失去“封禁用户”权限或管理员身份后，“群组管理功能”会被关闭；恢复权限后，你需要重新开启并检查设置。

“群组管理功能”关闭时，部分聊天和娱乐功能仍可能响应。要调整聊天行为，请在开启管理功能后检查群组的聊天设置。
