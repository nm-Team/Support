# 检查“机器人权限”和“群组功能管理权限” {#nmbot-群组功能所需权限说明}

如果你能打开群组设置，却无法删除消息或限制成员，请分别检查 nmBot 的权限和你自己的设置权限。Telegram 授予机器人的管理权限，决定它能执行哪些操作；群组对管理员的设置权限，决定你能修改哪些 nmBot 设置。

<span id="_2"></span>

## 检查 nmBot 的权限 {#需要基础管理员权限删除消息和限制用户}

你需要在 Telegram 的群组管理员列表中，将 nmBot 设为管理员，并按要使用的功能授予权限：

- “删除消息”：用于删除骚扰消息、按消息类型自动删除消息，以及删除关键词回复所匹配的原消息。
- “封禁用户”：用于封禁或禁言成员、入群验证，以及处理成员警告后的限制。
- “置顶消息”：用于 `/pin`、`/unpin` 和自动解除关联频道消息的置顶。

<span id="额外需要置顶消息权限"></span>
<span id="_3"></span>

如果 nmBot 因为失去管理权限而关闭了“群组管理功能”，请先恢复它在 Telegram 中的权限，再回到面板重新[启用“群组管理功能”](setup.md)。

## 检查你修改设置的权限 {#检查你修改设置的权限}

群主始终可以修改 nmBot 的群组设置。默认情况下，其他管理员需要拥有 Telegram 的“封禁用户”权限。

在面板的群组页面点按“你的权限”，可以查看你的设置权限。如果你是群主，可以打开“对 nmBot 的设置权限”，检查不同功能允许哪些管理员操作。订阅 nmBot+ 的群组还可以使用更细的权限分类和管理员例外设置。

如果你看到权限不足的提示，请让群主检查这一页的要求。仅仅能在 Telegram 中修改群组资料，并不一定能修改 nmBot 的设置。

<span id="_1"></span>

## 使用基础聊天功能 {#不需要管理员权限}

nmBot 不需要管理员权限就能提供部分聊天功能，例如 nmartChat、呼叫管理员、欢乐复读和普通的关键词回复。你在关键词回复中启用删除原消息、禁言用户等操作时，仍需要为 nmBot 授予相应的管理权限。
