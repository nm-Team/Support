# 设置“群组娱乐功能” {#群组娱乐功能}

你可以在面板的“对话”中选择群组，打开“群组娱乐功能”，分别设置[“欢乐复读”](repeat.md)、[“群友互动”](member-interactions.md)、[“禁言我”](banme.md)和[“消息过塑”](../../tools/message-quote.md)。修改这些设置需要对应的[群组功能管理权限](../admin-rights-and-features.md)。

<span id="_1"></span>

如果你需要聊天回复或频道评论，可以设置[“nmartChat”](../../nmbot-intelligence/nmartchat.md)或[“同频气氛组”](../automation/channel-commentary.md)。
