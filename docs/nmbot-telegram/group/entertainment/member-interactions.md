# 使用“群友互动” {#群友互动}

你可以回复群友的消息，发送 `/拍拍` 等动作，让 nmBot 生成带有双方名字的互动消息。没有回复对象时，互动对象就是你自己。

## 开启并使用“群友互动” {#群友互动的触发方式}

管理员可以在 nmBot 面板的“对话” → 目标群组 → “群组娱乐功能”中打开“群友互动”。修改设置需要娱乐功能的[群组功能管理权限](../admin-rights-and-features.md)。nmBot 需要能够在群组中发送消息。

1. 回复你希望互动的群友所发的消息。
1. 发送 `/拍拍`。nmBot 会生成你拍拍对方的消息。

你也可以回复 nmBot 生成的互动消息，继续与其中的对象互动。直接以英文字母开头的指令会留给普通指令处理；需要英文动作时，可以写成 `/$hello`。

## 添加动作后的文字 {#让我们来看看高级点的操作}

你可以用空格分隔动作和补充内容。例如，回复群友并发送 `/送给 一杯咖啡`，nmBot 会把补充文字放在对方名字后面。

动作中需要空格时，可以使用 `$space`，例如 `/认真地$space拍拍`。

## 插入名字、日期和时间 {#往消息里再加点料}

你可以在动作或补充文字中使用这些参数：

- `$from`：你的名字。
- `$to`：互动对象的名字。
- `$bot`：nmBot 的名字。
- `$date` 和 `$time`：生成消息时的日期和时间。
- `$space`：一个空格。
- `$he` 或 `$hideexclamation`：不添加结尾的感叹号。
- `$hl` 或 `$hidele`：不自动添加“了”。

例如，你可以发送 `/送给 一杯咖啡$he`，生成的消息就不会自动添加结尾感叹号。参数会在生成时替换为对应内容，不会原样显示。
