# 使用“nmBot Copilot”管理配置 { #nmbot-copilot }

如果你不确定某项功能在哪里设置，可以直接向“nmBot Copilot”描述目标。它可以解释 nmBot 的功能、提出配置更改，或引导你打开相应页面；需要执行操作时，请检查它列出的内容再确认。

## 前提条件 {#前提条件}

你需要[登录 nmBot 面板](../panel/launch.md)，或使用自己的 Telegram 账号与 nmBot 交互。管理群组或频道时，nmBot 需要已加入该对话，你也需要拥有相应的管理权限；Copilot 不会替你取得额外权限。

使用前，请了解 [nmBot 智能隐私](privacy.md)。

<span id="nmbot-copilot_2"></span>

## 开始对话 { #使用-nmbot-copilot }

在 Telegram 中，向 nmBot 发送 `/chat` 加上你的问题，例如：

```text
/chat 帮我设置新成员入群验证
```

在 nmBot 面板中，打开“nmBot Copilot”，在“询问我任何问题”中输入目标，再点按“发送消息”。它会显示处理进度，并在完成后提供答复或下一步操作。

你可以说明想要的结果，例如“每天晚上十一点到早上八点不允许发图片和视频”，或“帮我创建发送群规的关键词回复”。如果信息不足，继续补充群组、条件和时间等内容，再检查它提出的设置。

<span id="_2"></span>

## 选择要管理的群组或频道 { #以群组身份继续 }

在 nmBot 面板中，开始对话前点按输入框旁的头像，打开“选择对话”，选择目标群组或频道。如果没有可选对话，先[将对话添加到 nmBot 面板](../panel/managed-chats.md)。你也可以保持个人身份，先询问一般问题。

如果 Copilot 在私信中请求选择对话，使用返回的“选择群组继续”或“选择频道继续”按钮，选择 nmBot 已加入且你有权管理的对话。

正在进行的 nmBot 面板对话不能直接切换已经选定的群组或频道。要处理另一个对话，请点按“新对话”，再选择新的目标，避免把设置应用到错误的群组。

## 确认配置更改 {#确认配置更改}

当回复包含“建议的配置更改”时，检查设置名称、原值和新值。确认目标对话和内容后，点按“确认”。页面随后会显示各项更改的处理结果；如果某项失败，请阅读对应说明，再检查权限或订阅状态。

当回复显示“授权操作”或 Telegram 中的“确认操作”时，先展开“详情”，查看允许执行的操作，再决定是否点按“确认”。部分只读取信息的操作可能按你的设置自动执行，修改设置仍需要检查相应确认内容。

如果建议不符合你的意思，可以继续发消息修正要求。如果你还没有看到成功结果，请不要仅凭普通聊天文字判断设置已经完成。

<span id="_3"></span>

## 继续已有对话 { #继续聊天 }

在 Telegram 中，回复 Copilot 的消息即可继续同一段对话。每段对话属于发起它的账号，其他成员不能代替你参与或确认操作。

在 nmBot 面板中，点按“历史记录”，选择已有对话继续。这里也会显示同一账号在 Telegram 中与 Copilot 的对话。要重新开始，点按“新对话”。

<span id="_5"></span>

## 调整语言和反馈 { #语言支持 }

Copilot 会按你在 nmBot 或 nmBot 面板中选择的语言回复。你可以在 nmBot 面板聊天页打开“设置”，检查相关偏好。

<span id="反馈不正确的内容使用问题和建议"></span>

如果答复不正确，可以在消息下方选择“给予好评”或“给予差评”，并按需补充说明。其他使用问题和建议可以[发送反馈](feedback.md)。
