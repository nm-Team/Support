# nmBot 智能与隐私

nmBot 智能会使用与所选功能相关的信息来生成答复或处理内容。关于数据收集、使用、分享和保存的完整说明，请参阅[“nmBot 服务隐私政策”](../legal/privacy-policy.md)。

## 确认 Copilot 的操作

在[“nmBot Copilot”](copilot.md)中，配置更改需要你检查并确认，执行时仍会检查相应的管理权限和订阅要求。请查看各项操作的处理结果，确认更改是否完成。

“自动同意只读操作”默认关闭。开启后，Copilot 可以自动执行只读查询，无需逐次确认；发送消息、删除数据或修改配置仍需要你确认。你可以在 nmBot 面板的对话记录中查看读取的信息，也可以随时关闭这项设置，恢复对后续读取请求的逐次确认。

## 数据收集与使用

使用 Copilot 时，相关信息包括：

- 对话内容：你发送的问题、Copilot 的答复，以及继续对话时使用的历史内容。
- 配置和操作结果：所选群组或频道的相关设置，以及获准执行的查询和修改结果。
- 主动提交的反馈：你对答复的评价和补充说明。

对话内容和操作结果会保存在历史记录中。提交反馈或在公开社区分享对话前，请检查其中是否包含个人信息。

## 与第三方服务商的合作

nmBot 智能可能使用第三方服务处理消息和生成内容。相关对话内容、配置或查询结果可能交由这些服务处理，具体取决于使用的功能。

第三方服务的数据处理还受其隐私政策和服务条款约束。如果你对数据处理有疑问，或需要提出个人数据相关请求，可以[联系 nmTeam 支持](../support.md)获取帮助。
