# 反馈“nmBot 智能”问题 {#nmbot-智能反馈}

如果使用 nmBot 智能时遇到问题，你可以向 [nmTeam 支持机器人](https://t.me/nmteamsupportbot)反馈。请说明操作步骤、预期结果和实际提示，并在消息中加入标签 `#nmBotIntelligence`。

如果你要提交功能建议或与其他用户交流，可以使用 [nmTeam 社区](../../contact-us/forum.md)。截图、对话内容和诊断结果可能包含个人信息，公开发送后，其他人也能看到这些内容。
