# 使用“nmBot 智能” {#nmbot-智能}

你可以用 nmBot 智能获得使用帮助、配置建议、对话回复或频道评论。自动生成的内容可能出现错误，具体功能的授权范围和处理方式取决于你开启的设置。

## 选择“nmBot 智能”功能 {#nmbot-智能功能}

### 使用“nmBot Copilot” {#nmbot-copilot}

你可以用[“nmBot Copilot”](copilot.md)询问 nmBot 使用问题，或描述需要修改的群组、频道和个人设置。它提出配置或操作后，你可以检查内容并按提示确认。

### 使用“nmartChat+” {#nmartchat}

<nmbot-plus-icon></nmbot-plus-icon> 订阅 nmBot+ 的群组可以启用[“nmartChat+”](nmartchat.md)，在回复中继续之前的对话。

### 启用智能“骚扰消息拦截” {#骚扰拦截-20}

你可以在[“骚扰消息拦截”](../group/moderation/anti-spam.md)中启用 nmBot 智能识别，调整灵敏度和处理方式。开启“nmBot 智能智能操作”后，即使基础处理方式为“删除”，也可能根据识别结果封禁发送者。

### 设置“同频气氛组” {#同频气氛组}

你可以让新版[“同频气氛组”](../group/automation/channel-commentary.md)在频道讨论群评论帖子，并调整人设、发言风格和对话方式。

### 设置“关键词回复”的情绪条件 {#关键词回复情绪识别}

<nmbot-plus-icon></nmbot-plus-icon> 订阅 nmBot+ 的群组可以在[“关键词回复”](../group/automation/keyword-replies.md)中按消息情绪匹配规则，包括仇视言论、侮辱性言论、脏话和暴力言论。

### 了解“欢乐复读”的保护 {#欢乐复读保护}

你开启[“欢乐复读”](../group/entertainment/repeat.md)后，nmBot 会跳过识别为骚扰的文字，因此不保证所有重复消息都得到回复。

## 了解隐私保护 {#隐私保护}

你可以[了解 nmBot 智能与隐私](privacy.md)，确认相关数据的使用范围。

## 提交反馈 {#反馈}

如果回复不符合预期，或你希望提出建议，可以[反馈 nmBot 智能问题](feedback.md)。
