# 获取 nmBot 支持 {#nmbot-支持}

如果使用 nmBot 时遇到问题，你可以通过 [nmTeam 支持机器人](https://t.me/nmteamsupportbot)获取帮助。请说明你执行的操作、预期结果和实际提示，方便支持人员了解问题。

如果涉及付款，你可以在与 nmBot 的私信中发送 `/paysupport` 获取付款支持入口。如果遇到骚扰拦截误封，你可以先[查询记录并发起争议](tools/spam-appeals.md)，或向支持提供操作 ID。

截图和诊断结果可能包含个人信息。发送公开消息后，其他人也能看到其中的内容；访问令牌、密码和验证码不能用于公开反馈。

你也可以到 [nmTeam 官方群组](https://t.me/nmteamchat/20055)与其他用户交流。关于指令的用法，可以直接[查找 nmBot 指令](commands.md)。
