# nmTeam 账号帮助

你可以在这里查找 nmTeam 账号的注册、登录和安全设置指南。如果遇到问题，可以查看已知问题或联系支持。

## 什么是 nmTeam 账号？

nmTeam 账号是 nmTeam 服务的统一身份认证系统。你可以用它登录支持的 nmTeam 服务，例如在[绑定 Telegram 账号后登录 nmBot 面板](../nmbot-telegram/panel/authorization.md#%E7%BB%91%E5%AE%9A-nmteam-%E8%B4%A6%E5%8F%B7)。

## 常见问题

??? question "如何重置我的密码？"

    你可以在 [nmTeam 账号中心](https://accounts.nmteam.xyz/) 的登录页面点按“忘记密码”，重置密码。系统会向你的注册邮箱发送密码重置链接。

??? question "如何更改我的用户名？"

    登录 nmTeam 账号中心后，你可以在“个人资料”页面修改用户名。具体限制请查看页面提示。

??? question "如何删除我的账号？"

    如果你希望删除 nmTeam 账号，请[联系 nmTeam 支持](/contact-us/contact-support.md)获取帮助。账号删除后无法恢复，你将失去对所有关联服务的访问权限。
