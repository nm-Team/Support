# 注册 nmTeam 账号

## 打开 nmTeam 账号中心

打开 nmTeam 账号中心的[“注册账号”页面](https://accounts.nmteam.xyz/#/register)。

你也可以在登录页面点按页脚的“注册”。

nmTeam 账号注册页面看起来像这样：
![nmTeam 账号注册页面](/assets/images/shared/nmteam_account_register.png)

## 输入注册信息

注册 nmTeam 账号需要提供电子邮箱，并设置用户名和密码。

- “电子邮箱”：输入你的电子邮箱地址。
- “用户名”：输入要使用的用户名。
- “密码”：设置账号密码。
- “确认密码”：再次输入相同的密码。

随后，请在阅读后选中“我同意 nmTeam 账号服务协议和隐私政策”。
注册 nmTeam 账号即表示你同意遵守 nmTeam 的服务协议和隐私政策。

确认注册信息无误后，点按“注册”。

## 完成注册

如果注册成功，系统会向你的邮箱发送验证邮件。请打开邮件中的链接完成邮箱验证。
如果没有收到邮件，请检查垃圾邮件文件夹。如果仍然无法验证，你可以[联系 nmTeam 支持](../contact-us/contact-support.md)获取帮助。

## 解决问题

注册时可能出现以下提示：

| 提示信息                                             | 原因                                                     |
| :--------------------------------------------------- | :------------------------------------------------------- |
| 请输入用户名。                                       | 未输入用户名。                                           |
| 请输入电子邮箱。                                     | 未输入电子邮箱。                                         |
| 请输入密码。                                         | 未输入密码。                                             |
| 请输入确认密码。                                     | 未输入确认密码。                                         |
| 两次输入的密码不一致。                               | 两次输入的密码不一致，请重新核对。                       |
| 请阅读并同意 nmTeam 服务协议和隐私政策。             | 尚未同意服务协议和隐私政策。                             |
| 出现错误，可能是网络问题。请检查您的网络连接后重试。 | 无法连接到 nmTeam 服务器，请检查网络连接或确认服务状态。 |
| 此用户名已被使用。                                   | 用户名已被其他用户注册，请尝试其他用户名。               |
| 此电子邮箱已被使用。                                 | 电子邮箱已被其他用户注册，请尝试其他电子邮箱。           |
| 电子邮箱格式不正确。                                 | 电子邮箱格式不正确，请检查填写内容。                     |
| 昵称格式不正确。                                     | 用户名格式不正确，请检查填写内容。                       |
| 输入的密码不符合要求。                               | 密码不符合要求，请按页面提示重新设置。                   |
| 注册失败。                                           | 请联系 nmTeam 支持以获取帮助。                           |
