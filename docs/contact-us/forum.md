# nmTeam 社区

你可以在 nmTeam 社区与其他用户交流产品用法、讨论问题或提出建议。

## GitHub Discussions

在 [GitHub Discussions](https://github.com/orgs/nm-Team/discussions) 中参与讨论。

## Telegram 群组

加入 nmTeam 官方群组 [@nmteamchat](https://t.me/nmteamchat)，与其他用户交流。

## Discord

加入 [nmTeam Discord 服务器](https://discord.gg/kRegqfMx)，与其他用户交流。
